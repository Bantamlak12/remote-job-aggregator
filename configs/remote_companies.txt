# Remote-first and remote-friendly companies, by name. `aggregator discover-boards`
# looks each one up on Greenhouse, Lever and Ashby (a name is enough: the boards
# are addressed by a slug that is nearly always the company's name) and
# registers the boards that prove they are the company's. A name with no public
# board there is simply not found; adding a name costs a handful of requests.
# One name per line; blank lines and lines starting with # are ignored.
#
# "Name | domain.tld" adds the company's web domain: the board is then accepted
# only if its job text mentions that domain, which is the only proof that works
# for a name that is also an everyday word (Close, Linear, Ramp). A name made of
# everyday words with no domain is not looked up at all, and a name that shows
# up on more than one board is refused as ambiguous; both are logged so the
# domain can be added. The domains below were each checked against a live board.
